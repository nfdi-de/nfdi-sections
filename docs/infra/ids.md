# Working Group Infrastructure and Data Security (IDS)

The Information Security Working Group within NFDI’s Section Common Infrastructures brings together expertise to strengthen the security of research data and services. It promotes knowledge exchange and develops practical guidance on risk management, secure operations and incident response, supporting trustworthy infrastructures.
