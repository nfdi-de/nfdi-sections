# Create a new Calendar Entry

To create a new entry in the [Calendar](https://nfdi-de.github.io/nfdi-sections/docs/calendar):

* Go to the Sections Knoeledge Base Githib Repo: https://github.com/nfdi-de/nfdi-sections
* Click in "Issues" in the top navigation bar.
* Click on Button "New Issue"
* Select "New Calendar Event"
* Enter the data
* Click Button "Create"


# Delete or Change a Calendar Entry
To delete or change a calendar entry, you can edit the file https://github.com/nfdi-de/nfdi-sections/edit/main/static/calendar.json 
**Attention**: This file contains all calendar entries. When editing it, please be careful to keep the syntax intact.
