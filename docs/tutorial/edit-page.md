To edit an existing page:
* Open the Sections Knowledge Base website https://nfdi-de.github.io/nfdi-sections/
* Go to the page that you wish to edit 
* click on “Edit this page” (at the Bottom of the page)
* Edit the page Using [GitHub Markdown](https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax) and [Docusaurus Formatting](https://nfdi-de.github.io/nfdi-sections/docs/tutorial/markdown)
You can use the "Preview" tab to preview the result.
* Click in the "Commit Changes" Button
* Enter a short Commit Message. This message describes the change that you made, e.g. "Updated contact information". Optionally give more information in "Extended Description"
* Click Button "Propose Changes"

Your changes have now been saved. However, they will not be immediately displayed in the Knowledge Base Website because they need to be reviewed.
