To edit an existing page:
* Open the Sections Knowledge Base website https://nfdi-de.github.io/nfdi-sections/
* Navigate to the page that you wish to edit
* Click on “Edit this page” (at the bottom of the page)
* Edit the page using [GitHub Markdown](https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax) and [Docusaurus Formatting](https://nfdi-de.github.io/nfdi-sections/docs/tutorial/markdown)
You can use the "Preview" tab to preview the result
* Click in the "Commit Changes" button
* Enter a short Commit Message. This message describes the change that you made, e.g. "Updated contact information". This step is mandatory in the Git workflow, never leave it blank. Githubs AI tool Copilot will suggest a message, which you can accept or overwrite. You can optionally add more information in the "Extended Description"
* Click Button "Propose Changes"
* This opens a new page where you can submit your edit for review. Click "Create pull request" to send it in.

Your changes have now been submitted. However, they will not be immediately displayed in the Knowledge Base website because they need to be reviewed first.
